# RescueTwin-AI
El proyecto propone un sistema basado en ciencia de datos que simula el comportamiento de un robot cuadrúpedo en zonas de derrumbe. A partir de datos de sensores, el sistema predice el nivel de riesgo del entorno y recomienda si el robot debe avanzar, detenerse, cambiar de ruta o enviar una alerta al equipo de rescate.
